Features

  • This is an extension module for the Connect application!
  • Give your customers an external AI memory — a searchable brain that remembers every conversation and event.
  • Provider-neutral: works with Hindsight, Cognee or any engine through a simple pull contract — Odoo never calls the engine directly.
  • Automatic capture of real customer correspondence — emails and chatter messages on any document.
  • "Customer summary" on the partner form — ask the memory brain what it knows about a customer.
  • Backfill years of historical correspondence into memory with one click or a scheduled job.
  • More memory sources coming! Send us your request.
