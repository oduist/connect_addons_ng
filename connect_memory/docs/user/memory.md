# Customer Memory

When Customer Memory is enabled, Connect quietly builds an AI memory of each
customer from your day-to-day work — the emails and messages you exchange, and
(with the Sale add-on) their orders, invoices and payments. You can then ask
that memory for a summary instead of digging through the history yourself.

## The Memory smart button

Open any customer and you'll see a **Memory events** smart button with a count.
Click it to see everything Connect has remembered about that customer — each
captured message or business event, with the record it came from.

## Get a customer summary

On the customer form, click **Customer summary**. Connect asks the memory engine
for a concise summary of everything it knows about that customer. The answer
arrives asynchronously — it appears as an **Inbox** entry (Connect → Memory →
Inbox) once the engine responds, with the readable summary text.

## Load past correspondence

New emails and messages are remembered automatically. To also pull in a
customer's **older** correspondence, click **Load correspondence to memory** on
their form. Connect queues their past emails and chatter messages; you'll get a
short notice of how many were newly added. Running it again is safe — already
remembered items are skipped.

!!! note
    Only real correspondence with an **external** contact is captured — internal
    notes between colleagues and system messages are ignored.
