## Post

"They definitely agreed to that on the call." Two weeks later, nobody can find the call. 🎧

**Oduist Connect Project** adds a **Recorded Calls** tab to both the task and the project. Open the task, press play, hear what was actually agreed:

⏺️ Recordings inherit the call's link — the task if there is one, otherwise the project
📋 The tab lists start time, caller and called number, with an inline player
🔘 A **Calls** smart button on task and project opens the full linked call history
🤖 With AI summaries on, the summary of each call is posted to the task chatter
🚫 No download, no shared drive, no "which folder was that in"

Scope disputes get shorter when the evidence lives in the same record as the work.

Where do your client call recordings live right now — honestly? 👇
