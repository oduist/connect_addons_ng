Connect your Asterisk PBX to Odoo!

Bring your existing FreePBX, Issabel or plain Asterisk into Odoo with a built-in web phone!

This module is provided as a 30-day free trial. After the trial period ends, a purchase is required to continue using the application. For pricing and other details, visit https://oduist.com/pricing

Features

  • This is an extension module for the Connect application!
  • Works with your existing Asterisk PBX through a lightweight sidecar agent — no rip-and-replace.
  • Live call events inside Odoo: see who is calling and log every call automatically.
  • One-click calling from any Odoo record through AMI Originate.
  • A JsSIP web phone right in the browser — call, answer and hang up without leaving Odoo.
  • Guided PJSIP and manager.conf configuration snippets to get connected fast.
  • More Asterisk features coming! Send us your request.
